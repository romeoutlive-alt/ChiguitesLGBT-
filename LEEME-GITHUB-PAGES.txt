CHIGUITES · WEB PARA GITHUB PAGES

Esta copia está preparada para publicarse en:
https://romeoutlive-alt.github.io/chiguiteslgbt-/

PUBLICACIÓN
1. Extrae el ZIP en tu ordenador.
2. En el repositorio romeoutlive-alt/chiguiteslgbt-, abre la rama configurada para GitHub Pages (actualmente main).
3. Sube el contenido extraído a la raíz del repositorio, conservando todas las carpetas. La raíz debe contener index.html y las carpetas assets, images, etc.; no pongas todo dentro de una carpeta adicional.
4. Confirma los cambios y espera a que termine el despliegue de GitHub Pages. Después abre la dirección anterior y recarga la página.

IMPORTANTE · FORMULARIO DE SOCIOS
GitHub Pages no ejecuta PHP. Por eso api/socios.php no puede recibir ni enviar las solicitudes desde GitHub Pages. El formulario necesita un servidor compatible con PHP o un servicio de backend seguro y configurado antes de utilizarse. No lo pruebes con datos personales reales hasta tenerlo configurado y comprobado. Se conserva el archivo PHP original, sin afirmar que funcione en GitHub Pages.

CAMBIOS
Se han corregido las rutas del sitio, recursos y navegación para el subdirectorio /chiguiteslgbt-/. Se ha probado localmente la apertura de las seis páginas y la navegación en tamaños de móvil y ordenador.

El ZIP recibido contiene una web ya compilada, no el proyecto fuente. Si se vuelve a generar la web desde el proyecto original sin configurar allí la misma ruta base, estos cambios pueden perderse.

SEDE INTERNA
El botón del pie abre /sede/ en esta misma web. El acceso utiliza Supabase Auth y una lista de cuentas autorizadas en la tabla sede_accesos, protegida con RLS. La clave publicable de proyecto es pública por diseño y no concede acceso administrativo; nunca subas contraseñas o claves secretas al repositorio.

Solo se ha autorizado la cuenta de coordinación. Las carpetas se leen de la tabla sede_carpetas de Supabase, protegida con RLS y visible por ahora solo para coordinación activa. Son registros organizativos, no almacenamiento de archivos: las salas no están vinculadas a documentos ni se han importado archivos desde los ZIP, Notion o Drive. El explorador de prueba consulta Drive por separado si se autoriza. Antes de trabajar con información personal, hay que implementar y probar almacenamiento privado, permisos específicos y copias de seguridad. GitHub Pages es público; no pongas documentos privados en el repositorio. Para recuperar o cambiar la contraseña, usa las herramientas de Supabase; no se ha conectado aún un formulario de recuperación.


CONEXIÓN A DRIVE (PRUEBA)
El explorador de Drive solicita a Google permiso de solo lectura de toda la cuenta de la asociación. Cada usuario debe autorizar su cuenta; esta primera versión solo acepta la cuenta de coordinación. El permiso no incluye modificar ni borrar. La aplicación está en prueba y sin verificar por Google; sus límites pueden requerir volver a autorizar. El token se mantiene solo en memoria durante la sesión y no se publica en GitHub. El explorador muestra la organización original de Drive; adicionalmente se pueden generar propuestas temporales para los cajones. No se han cargado ni movido documentos. Los PDF y documentos de Google exportables pueden mostrarse en el visor de PDF del navegador; puede no funcionar en todos los dispositivos. Se mantiene la opción de descargar. Otros formatos pueden necesitar descarga. La desconexión borra el token de la sesión, pero no revoca la autorización en la cuenta de Google. La integración real requiere pruebas del acceso, de las vistas previas y de los permisos en Google antes de usarla con datos sensibles.

ORGANIZACIÓN PROVISIONAL
Con Drive conectado, el botón «Organizar en la sede» revisa los nombres, tipos y rutas de los archivos accesibles de Mi unidad en el navegador y propone cajones basándose en reglas de nombres. No analiza el contenido ni mueve, copia, modifica o borra los originales. Las propuestas no se guardan: hay que volver a generarlas tras desconectar o recargar, y todavía no se pueden corregir ni guardar manualmente. Puede haber errores; lo no reconocido va a Por clasificar, incluso otros archivos de la cuenta. No incluye archivos fuera de Mi unidad ni descomprime ZIP. No se ha probado con el Drive real, solo con datos ficticios; revisar especialmente información personal o de salud antes de ampliar accesos.
